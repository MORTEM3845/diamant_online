# Справочные материалы

Официальные буклеты были скачаны для проверки правил. Их адреса, размеры и SHA-256 указаны в `sources.json`. Локальные PDF исключены из Git и не входят в публичную веб-игру; права на текст и иллюстрации принадлежат соответствующим правообладателям.

Чтобы скачать тот же набор в свою рабочую копию:

```sh
npm run references
```

Скрипт проверяет контрольные суммы и не заменяет уже скачанный файл с другой контрольной суммой. Если издатель обновил буклет, сначала проверьте изменения правил. Оригинальный обзор механик и различий редакций: `docs/research/rules-audit.md`. Игровые иллюстрации в `public/art/` созданы отдельно для этого проекта.
